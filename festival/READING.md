## 箇所1：好きなことを最大3つまで選択する処理

```swift
Button {
    if interests.contains(interest) {//もし、今タップした項目が、すでに選択済みだったら
        interests.removeAll { $0 == interest }//今タップした項目と同じものを、選択済みの配列から削除する
    } else if interests.count < 3 {//じゃないなら、まだ3個選んでいなければ、
        interests.append(interest)//今タップした項目を、選択済みの配列に追加する
    }
```

**何をしているか：**
「好きなこと」をタップすると選択できて、もう一度タップすると解除できる。ただし、選択できるのは最大3個まで。

**なぜこう書くのか：**
分からない

**もしこう書かなかったら：**
else if interests.count < 3 { の 3 を 5 に変更して、「好きなこと」を選択しました。通常は3個までしか選択できませんが、変更後は5個まで選択できるようになりました。試したあと、元の 3 に戻しました。

## 箇所3：写真がある場合とない場合で、表示する画像を切り替える処理

```swift
if let data = photoData,//写真データが存在するか確認し、取り出す
   let photo = UIImage(data: data) {//写真データを画像に変換できるか確認する
    Image(uiImage: photo)//撮影した写真を表示する
        .resizable()//画像のサイズを変更できるようにする
        .scaledToFill()//表示領域を埋めるように画像を拡大・縮小する
} else {//写真がない、または画像に変換できなかった場合
    Image(systemName: "person.crop.circle")//標準の人物アイコンを表示する
        .resizable()
        .scaledToFit()//画像全体が収まるように表示する
        .foregroundStyle(MEETIStyle.green)//アイコンをMEETIの緑色にする
}
```

**何をしているか：**
写真の撮影は任意なので、写真を撮らなかった人でもプロフィール画面のレイアウトが崩れないようにするため。

**なぜこう書くのか：**
わからない

**もしこう書かなかったら：**
`Image(systemName: "person.crop.circle")` の `"person.crop.circle"` を `"star.fill"` に変更して、写真を撮影していない状態で画面を表示しました。
通常は人物アイコンが表示されますが、変更後は星のアイコンが表示されました。
試したあと、元の `"person.crop.circle"` に戻しました。
