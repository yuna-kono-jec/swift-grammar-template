## 2. 演習の記録（4点セット）

### 演習1：60点以上だった人の名前を、names の並び順のまま passers に集めてください

**使ったプロンプト：**
コードの内容がよくわかっていないけど動いてしまったので、丸ごと聞いた。

// 演習1: 60点以上だった人の名前を、names の並び順のまま passers に集めてください
//        0..<names.count で回して、if で選びます

var passers: [String] = []
for i in 0..<names.count {
    if scores[i] >= 60{
        passers.append(names[i])
    }
}
print(passers)
これはなんで正解ですか？

**AIの出力から自分が変えた点：**
変えてない。理由は既に正解しているから。

**自分の言葉での説明（何を受け取り、何をして、何を返す）：**
scores[i] で点数を調べて、合格した人の names[i] だけを新しい配列に追加している。
scores[i] と names[i] は別の配列だけど、同じ i を使うことで同じ人を指せる。

**壊す実験（何を変えたら、何が起きたか）：**
if scores[i] >= 60 を if scores[i] > 60 に変更した。
すると、60点の「佐藤みなみ」が合格者の配列に追加されなくなり、合格者が4人から3人になった。
`>=`　は60点を含むが、`>` は60点を含まない。

### 演習2：scoreOf を for-in で回して、80点以上の人数を highScorers に入れてください

**使ったプロンプト：**
forの中がわからない。`for (_, score) in scoreOf` が何をしているのか教えて

**AIの出力から自分が変えた点：**
AIの説明を参考に、80点以上を判定する条件を自分で考えた。最初は `80 <= score` と考えたが、一般的な書き方の `score >= 80` を使った。

**自分の言葉での説明（何を受け取り、何をして、何を返す）：**
scoreOf という辞書から点数を1つずつ取り出す。`_` は名前を使わないという意味。
取り出した点数が80点以上だったら、`highScorers` に1を足す。
これを全員分繰り返して、最終的に80点以上の人数を `highScorers` に入れる。今回は2人になる。

**壊す実験（何を変えたら、何が起きたか）：**
`if score >= 80` を `if score >= 90` に変更した。
すると、80点以上だった2人のうち、91点の1人しか条件に当てはまらなくなり、`highScorers` が1になった。
確認テストの結果がOKからNGに変わった。
条件式の数字を変えると、数える対象が変わることがわかった。
